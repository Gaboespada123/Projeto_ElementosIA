# Projeto_ElementosIA

Análise de dados e previsão de resultados de dietas através de técnicas de inteligência artificial e ciência de dados.

## Descrição do Projeto

Este projeto aplica técnicas de análise exploratória de dados, clustering e modelos de aprendizagem supervisionada a um conjunto de dados sobre pacientes, planos dietéticos, nutricionistas e resultados de intervenções nutricionais.

### Objectivos

- Integração e limpeza de dados multifontes
- Análise exploratória detalhada
- Identificação de padrões através de clustering
- Desenvolvimento de modelos preditivos
- Avaliação crítica de resultados

## Execução dos Scripts

### 1. Limpeza de Dados
```bash
python scripts/limpeza_dados.py
```

### 2. Pré-processamento
```bash
python scripts/preprocessamento_final.py
```

### 3. Treinamento de Modelos
```bash
python scripts/modelo_baseline.py
```
